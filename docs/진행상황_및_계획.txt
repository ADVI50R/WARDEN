WARDEN 관제 실습 - 진행 상황과 앞으로의 계획 (팀원용)
작성일: 2026-10-13

이 문서는 "지금까지 뭘 만들었고, 앞으로 뭘 할 건지"를 팀원들이 쉽게 볼 수 있게 정리한 것입니다.
어려운 말은 중간에 풀어서 적었습니다.

==================================================
1. 한 줄 요약
==================================================
공격을 자동으로 알아채고(탐지), 필요하면 막아주는(차단) 프로그램 "WARDEN" 을 만들었고,
가상 컴퓨터 두 대(서버 / 공격자)로 실제로 동작하는 것을 확인했습니다.
아직 남은 일은 "탐지 규칙 시험을 마저 하기", "규칙 더 추가하기", "발표 준비" 입니다.

- 실습에 쓰는 컴퓨터(학교 컴퓨터)는 다른 사람에게 접속을 공유하지 않습니다.
  공유하는 것은 "우리가 만든 파일"과 "시험 결과"뿐입니다.
- 지금 WARDEN 은 "탐지만 하는 모드(dry-run)" 입니다. 공격을 발견하면 기록은 남기지만 실제로 막지는 않습니다.
  (실수로 우리 컴퓨터를 막아버리지 않게 하려는 안전장치입니다.)

==================================================
2. 용어 설명
==================================================
- 가상 컴퓨터(VM): 컴퓨터 안에 만든 또 하나의 가짜 컴퓨터. 공격 연습을 안전하게 하려고 씁니다.
- 서버 VM: 지켜야 하는 쪽 컴퓨터. 여기서 WARDEN 이 돌아갑니다.
- 공격자 VM: 일부러 공격을 해보는 쪽 컴퓨터. 서버를 시험할 때만 씁니다.
- 탐지: "지금 공격이 오고 있다"고 알아채는 것.
- 차단: 공격하는 컴퓨터가 더 이상 접근하지 못하게 막는 것.
- 규칙: "이런 모양이면 공격이다"라고 적어둔 판단 기준. 규칙마다 파일이 하나씩 있습니다.
- dry-run: 연습 모드. 탐지만 하고 실제로 차단하지는 않습니다.
- 대시보드: 탐지된 내용, 차단 목록, 규칙을 웹 화면으로 보고 조절하는 관제 화면.

==================================================
3. 구성 (그림으로 보면)
==================================================
  [서버 VM]  <------ 내부 연결 ------>  [공격자 VM]
  WARDEN 이 지켜봄                    공격을 시험해 봄
  대시보드로 화면 확인
- 두 VM 은 인터넷과 연결되지 않은, 둘만 쓰는 내부 네트워크로 이어져 있습니다. 그래서 실제 공격 연습을 해도 밖에 영향이 없습니다.

==================================================
4. 지금까지 한 것
==================================================
[WARDEN 프로그램 (warden.py)]
WARDEN 은 네트워크로 오가는 신호(패킷)를 계속 지켜보다가 아래 공격을 알아챕니다.
  1) 포트 스캔      : 어느 문이 열려 있는지 여기저기 두드려 보는 행동 (도둑이 집을 살피는 것과 비슷)
  2) SYN 플러드     : 접속 요청을 엄청나게 보내서 서버를 지치게 하는 공격
  3) 핑 플러드      : 확인 신호(ping)를 엄청나게 보내서 서버를 지치게 하는 공격
  4) SSH 무차별 대입: 원격 접속 비밀번호를 계속 바꿔가며 맞춰 보는 공격
  5) 텔넷 접근      : 오래되고 위험한 원격 접속 방식(텔넷)으로 들어오려는 시도
  6) ARP 변조       : "내가 그 컴퓨터다"라고 거짓말해서 통신을 가로채려는 공격
  7) 대량 유출      : 데이터가 한꺼번에 밖으로 나가는 상황 (알림만 하고 차단은 하지 않음)
발견하면 기록을 남기고, 필요하면 해당 컴퓨터를 자동으로 차단합니다.

[탐지 규칙]
- 규칙은 rules/ 폴더에 파일 하나씩 있습니다.
- 프로그램을 다시 켜지 않아도 5초 안에 바뀐 규칙이 적용됩니다.
- 대시보드에서 규칙을 켜고 끄고, 고치고, 지우고, 새로 만들고, 검색할 수 있습니다.

[대시보드]
- 탐지 이벤트, 차단 목록, 컴퓨터(IP)별 기록, 규칙 관리를 한 화면에서 봅니다.
- 화면의 슬라이드 하나로 "연습 모드(dry-run)"와 "실제 차단"을 바꿀 수 있습니다.
- 서버 없이 화면 모양만 보고 싶으면 preview/index.html 을 브라우저로 열면 됩니다 (예시 데이터).

[시험 결과]
- 가짜 신호로 확인하는 자체 시험(selftest.py): 44개 중 44개 통과
- 공격자 VM 으로 직접 시험(연습 모드): 포트 스캔, 핑 플러드, SSH, 텔넷은 탐지되는 것을 확인했습니다.
- 아직 안 해본 시험: ARP 변조, 대량 유출, 그리고 "실제 차단" 모드.

[환경]
- 기존 환경에서 만든 두 VM 을 학교 컴퓨터로 옮겨서 다시 동작하는 것을 확인했습니다.

==================================================
5. 알아두면 좋은 점
==================================================
- 실습용 컴퓨터가 가끔 저절로 꺼질 때가 있습니다 (학교 서버 쪽 사정으로 보이며, 교수님께 알릴 예정).
  그래서 시험 결과(화면 캡처, 기록)는 그때그때 파일로 저장해 두면 안전합니다.
- 컴퓨터 안에서 또 컴퓨터를 돌리는 구조라서 VM 이 조금 느립니다. 천천히 켜지는 것은 정상입니다.

==================================================
6. 앞으로 할 일 (순서대로)
==================================================
1) 남은 탐지 규칙 시험하기
   - ARP 변조, 대량 유출 시험 (명령은 attack_test_guide.md 에 있음)
   - "실제 차단" 모드로도 한 번 확인 (공격자 컴퓨터가 정말 막히는지)
2) 시험이 끝나면 되돌려 놓기
   - 시험하려고 꺼둔 규칙을 다시 켜기, 슬라이드를 "연습 모드"로 되돌리기
   - 정리된 상태를 그대로 저장해 두기 (가상 컴퓨터 스냅샷 = 컴퓨터의 "저장 지점")
3) 탐지 규칙 10개 정도 더 만들기
   - 형식은 dashboard/README.md 에 설명되어 있고, 규칙 파일을 하나 추가하면 됩니다.
4) 알림 기능 추가하기
   - 공격이 탐지되면 관리자에게 이메일로 알려주는 기능 (아직 안 만듦)
   - 먼저 정할 것: 어떤 메일 계정을 쓸지, 비밀번호를 어떻게 안전하게 보관할지,
     인터넷이 없는 내부 네트워크에서 어떻게 보낼지
5) 발표(시연) 준비
   - 실습 컴퓨터를 다른 사람에게 보여주지 않으므로, 시연 화면은 "녹화 영상 또는 화면 캡처"로 준비합니다.
   - 순서 예시: 공격 시작 -> 대시보드에 탐지 표시 -> 차단 확인
6) 공유용 파일 묶음 만들기
   - 코드, 문서, 예시 화면, 시험 결과만 모아서 전달합니다.
7) 더 해보고 싶은 것 (여유가 있으면)
   - 스크립트로 규칙 만들기, 플러그인 결과를 대시보드 화면에 바로 표시하기

==================================================
7. 팀원이 해볼 수 있는 것
==================================================
- 대시보드 모양 구경하기: warden/preview/index.html 을 더블클릭
- 시험 방법 읽어보기: warden/attack_test_guide.md (각 공격을 어떻게 흉내 내는지 나와 있음)
- 규칙 아이디어 내기: 어떤 공격을 더 잡으면 좋을지 생각해서 알려주기 (규칙 형식: dashboard/README.md)
- 환경 전체 순서가 궁금하면: warden/lab_setup_guide.txt

==================================================
8. 관련 파일
==================================================
- warden/README.md                 : 프로그램 설명과 사용법

- warden/rules/                    : 탐지 규칙 파일들
- warden/dashboard/                : 웹 대시보드 (사용법은 dashboard/README.md)
- warden/selftest.py               : 가짜 신호로 하는 자체 시험

- warden/preview/index.html        : 대시보드 예시 화면 (서버 없이 열림)
- warden/lab_setup_guide.txt       : 환경 준비 순서
